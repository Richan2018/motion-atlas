# Motion Archive · UI 与动效精选

公开的静态设计参考资料库，包含 UI 设计、UI 动效、趣味交互、AI 产品宣传和 AI 制作动画。

## GitHub Pages 部署

本仓库根目录直接提供网页，无需 npm、构建依赖或服务器。GitHub Pages 选择发布分支的 `/ (root)` 目录即可。`.nojekyll` 保持原始静态文件发布。所有应用资源使用相对路径，可用于用户主页或项目子路径。

## 更新资料

`source-data.json` 是维护数据，`data.json` 是网页读取的数据。两者只含公开精选，无账号资料或私人对话。

1. 获取本仓库最新版本。
2. 按既有 schema 幂等追加日期和案例，保留历史内容、作者、原链接、作品日期、热度观察日及观看限制。
3. 同一原作不能跨模块重复计数；不要为达到配额编造内容。
4. 运行 `python3 scripts/prepare-data.py` 和 `node --check app.js`。
5. 提交数据变更后核验 Pages 发布成功，以及线上日期、总量、筛选和全文。

目前归档：2026-10-26 至 2026-11-06，共 12 天、231 个案例。历史不足新配额不补造。首次迁移时仅将一处历史交付流程说明改为“已核对历史归档，避免重复收录”，所有案例正文、原链接、热度、观看限制保留。
